# Trail log

A walking guide saw a stop from a previous trip on a fresh itinerary. Each call to record_stop(name) starts a separate trip. When a list is supplied as stops, append the stop to that list. Return a list of the stops in order.

Record your diagnosis and prediction in the Instructor before editing trips.py. Repair the behavior and write your own regression test in test_regression.py at the project root using Python’s unittest. Exercise the public API and check the expected behavior. Use **Verify repair and test** to check your work.
