# Print batches

A print operator opened a new batch and saw an unexpected label count. A new Batch starts empty. Its add(label) method adds one label, keeps repeats and returns the number of labels in this batch. The labels attribute lists them in order.

Record your diagnosis and prediction in the Instructor before editing labels.py. Repair the behavior and write your own regression test in test_regression.py at the project root using Python’s unittest. Exercise the public API and check the expected behavior.
