# Ferry fares

A family disputed the fare for a child. The published fare is two credits for passengers aged twelve or younger and five credits for older passengers. fare(age) returns the fare for one passenger given their age in whole years.

Record your diagnosis and prediction in the Instructor before editing fares.py. Repair the behavior and write your own regression test in test_regression.py at the project root using Python’s unittest. Exercise the public API and check the expected behavior.
