# dhimantAI desktop builds

Private build inputs exported from commit `b92eca2a1e0daccafedd5f9dd2f4e6d49d2b6a5f`.

The source of truth is the Bitbucket repository. Only desktop inputs are mirrored here; backend, Flutter and repository history are excluded. Run the Custom desktop preview workflow with the staging environment. Configure FLUTTER_STAGING_ENV_JSON as an Actions secret containing only LIVEKIT_TOKEN_URL and LIVEKIT_TOKEN_SECRET.

Installers and their SHA-256 build receipts are retained as private workflow artifacts. Publishing them to dhimant.ai is a separate release step.
